# Current Review TC Notes

이 파일은 QA/리뷰 중 실제로 확인된 테스트케이스별 재현 질문과 오류 포인트를 누적한다.

## 사용 규칙

- 오류 수정, 분석, 배포 전 회귀 영향 검토 시 `FIX_LOG.md` 다음으로 이 파일을 확인한다.
- 관련 TC가 있으면 사용자에게 해당 TC 번호와 `review_question`을 먼저 공유한다.
- 원래 TC 정의는 `tstation-ai/eval/test_cases_from_excel.json`을 기준으로 확인한다.
- 이 파일은 원래 TC의 overlay다. `review_question`은 리뷰 중 실제 사용된 질문, `focus`는 현재 확인된 개선 포인트다.
- 새 리뷰 케이스가 생기면 기존 TC 아래에 내용을 추가하고, 기존 항목을 삭제하지 않는다.
